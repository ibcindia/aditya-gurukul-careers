# Aditya Gurukul Careers

Responsive static front-end starter for an education recruitment portal.

Included public pages: Home, About, Jobs, Job Details, Candidate Registration, Candidate Login, Candidate Dashboard, Profile, Contact, Privacy Policy and Terms.

Included admin pages: Admin Login, Dashboard, Candidates, Jobs, Applications and Settings.

## Important
This is a front-end preview only. Forms do not save or transmit data. Authentication, role-based authorisation, database, document storage, audit logs, consent records, spam protection and server-side validation are not implemented. Do not collect real candidate data until a secure backend (such as Firebase Authentication, Firestore and Storage with strict security rules) is configured and tested.

Job listings are sample placeholders, not confirmed vacancies. Review legal/privacy documents before publishing.
